# Codveda Technologies — Machine Learning Internship

This repository contains all machine learning projects completed as part of the Codveda Technologies Machine Learning Internship. The internship is structured across three difficulty levels — from foundational regression to advanced neural networks and support vector machines — with each task delivered as a fully documented, reproducible Jupyter notebook built for Google Colab.

Every notebook follows the same end-to-end structure: mounting storage, loading and cleaning data, exploratory data analysis with saved visualizations, preprocessing, model training, evaluation, and a conclusion written from the model's actual computed results rather than placeholder text.

**Author:** Lady
**Background:** BS Data Science student
**Environment:** Google Colab
**Core stack:** Python, pandas, numpy, scikit-learn, TensorFlow/Keras, matplotlib, seaborn, scipy
